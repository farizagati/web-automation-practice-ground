Protected Content

This simulates a page protected by Digest Authentication. In a real scenario, the browser would handle the SHA-256/MD5 challenge-response automatically.

How Digest Auth Works

  1. Client requests a protected resource
  2. Server responds with 401 and a nonce
  3. Client hashes username, password, nonce, and other values
  4. Client sends the hash (not the plain password)
  5. Server verifies the hash
