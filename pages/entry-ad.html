Testing Tips

  • Wait for modal to appear before interacting
  • Find and click the close button
  • Handle modals appearing on page load
  • Use explicit waits for modal visibility
// Wait for modal to be visible
modal = WebDriverWait(driver, 10).until(
    EC.visibility_of_element_located((By.ID, "modal"))
)

// Close the modal
close_btn = driver.find_element(By.ID, "close-modal")
close_btn.click()

// Wait for modal to disappear
WebDriverWait(driver, 10).until(
    EC.invisibility_of_element_located((By.ID, "modal"))
)
