Advanced XPath: SVG & Graph Elements

This challenge requires special XPath syntax to interact with SVG elements due to XML namespace handling.

⚠️ The Challenge: XML Namespaces

SVG elements use the http://www.w3.org/2000/svg namespace. Standard XPath queries often fail because:

  • XPath treats namespaced elements differently than HTML
  • //svg won't match <svg xmlns="...">
  • You must use local-name() or namespace-aware queries

❌ FAILS: //svg/circle
✓ WORKS: //*[local-name()='svg']//*[local-name()='circle']

Interactive Bar Chart

Hover over the circles (data points) to see tooltips. Each element has unique attributes for targeting.

XPath Solutions for SVG

Target the SVG Root

//*[local-name()='svg']
//*[name()='svg']
//svg:svg (with namespace prefix registered)

Target Circle Elements

//*[local-name()='circle']
//*[local-name()='svg']//*[local-name()='circle']
//*[local-name()='circle'][@id='point-apr']

Target by Data Attributes

//*[local-name()='circle'][@data-value='100']
//*[local-name()='rect'][@data-month='April']

Target Path Elements

//*[local-name()='path'][@id='trend-line']
//*[local-name()='path'][contains(@d, 'M 95')]

Automation Code Examples

# Selenium Python - Find SVG circle
circle = driver.find_element(
    By.XPATH, 
    "//*[local-name()='circle'][@id='point-apr']"
)

# Get data attribute
month = circle.get_attribute("data-month")  # "April"
value = circle.get_attribute("data-value")  # "100"

# Hover to trigger tooltip
from selenium.webdriver import ActionChains
actions = ActionChains(driver)
actions.move_to_element(circle).perform()

# Verify tooltip appeared
tooltip = WebDriverWait(driver, 5).until(
    EC.visibility_of_element_located((By.ID, "svg-tooltip"))
)

# Playwright
const circle = await page.locator('circle#point-apr');
await circle.hover();
await expect(page.locator('#svg-tooltip')).toBeVisible();
